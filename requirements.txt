# Python dependencies for this repo.
#
# Install: python3 -m pip install -r requirements.txt
# Python: 3.10 to 3.13. The cht-conf compile step (Backend/compile-demo, scripts/compileLocked.ts)
# runs CHT's bundled pyxform zipapp, which does not run on 3.15.
#
# Every Python file in the repo was checked. Only one third-party package is imported:
#
#   Backend/extraction/run_extraction.py    boto3 (Bedrock Runtime converse)
#   Backend/cross-check/run_extraction.py   boto3 (Bedrock Runtime converse)
#
# These use only the standard library and need nothing from pip:
#   Backend/extraction/prepare_input.py, Backend/cross-check/prepare_input.py
#   Backend/extraction/build_flow.py, Backend/cross-check/build_flow.py
#   Backend/validation/compare_outputs.py
#
# The Backend container (Dockerfile) runs only prepare_input.py, so it needs no pip packages.
# This file is for running the extraction and cross-check scripts locally.

# Floor is 1.34.116: it is the first release whose bedrock-runtime client has converse().
# boto3 1.34.0 to 1.34.115 install fine but fail at client.converse(...) with AttributeError.
boto3>=1.34.116,<2
